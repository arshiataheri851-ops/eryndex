# POUR / PLAY — Coffee Studio

An immersive specialty-coffee landing page concept created by ERYNDEX.

## Features
- Responsive editorial layout for desktop and mobile
- Procedurally modelled floating coffee beans rendered with Three.js
- Pointer-responsive 3D scene and gentle floating motion
- Scroll-triggered section reveals
- CSS-built espresso cup and product packaging illustrations
- Reduced-motion support and mobile navigation

## Run locally
Open `index.html` through a local static server from the repository root:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/website/demos/pour-play/`.

Three.js and web fonts are loaded from public CDNs, so an internet connection is needed for the full visual experience.

## Status
Visual concept/demo. Product names, tasting notes, and contact details are illustrative and are not a live commerce operation.
