04 / TECHNICAL TRANSPARENCY

Clear about what
it is — and isn't.

We prefer precise engineering claims over inflated AI promises. The current implementation is a retrieval API, not an autonomous answer-generation system.

Implemented in the current codebase

FastAPI endpoints · PostgreSQL full-text search with GIN indexing · tenant separation · API-key authentication · document ingestion · ranked passages and citations · Persian/Arabic normalization · retrieval evaluation metrics · Docker and automated tests.

Not claimed by this version

No vector embeddings, semantic or hybrid retrieval, LLM-generated answers, or fine-tuning are represented as implemented features. These can be considered as future extensions, with separate validation.
